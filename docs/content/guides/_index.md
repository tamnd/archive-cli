Each guide takes one job and shows it end to end, with the flags that matter and
the pipelines they enable. Start anywhere; they do not depend on each other.

- [Searching](/guides/searching/) builds Lucene queries, sorts, projects
  fields, and pages through large result sets.
- [Items and metadata](/guides/items-and-metadata/) reads the metadata record,
  a friendly summary, single fields, and file listings.
- [Downloading](/guides/downloading/) pulls files with verification, resume,
  and concurrency.
- [Uploading](/guides/uploading/) pushes files into your own items and removes
  them.
- [The Wayback Machine](/guides/wayback/) finds, fetches, and creates web
  captures.
